Minestom 기반의 서버를 Spigot이나 Paper처럼 친숙하고 빠르게 개발할 수 있도록 기본적인 틀을 개인적으로 만들어보는 실험용 프로젝트입니다.

기존 Minestom의 틀을 어느정도 잡아서 활용하는게 주 목적입니다. 다만, AI의 정밀한 도입, 월드 생성의 세밀한 활용등의 틀은 빠져있을 예정입니다.

---

## ✨ 핵심 기능 (Key Features)

* **🔌 에뮬레이트된 플러그인 시스템:** Spigot에서 플러그인을 넣듯, plugins 폴더의 구현.
* **💬 기본 권한 체계:** 기본적인 펄미션 권한 체계를 제작.

## 🤝 기여하기 (Contributing)

* 이 프로젝트는 오픈소스로 운영되며, Minestom을 더 쉽게 다루기 위한 모든 아이디어를 환영합니다!

1. 새 기능 브랜치를 생성합니다 (git checkout -b feature/AmazingFeature).

2. 변경 사항을 커밋합니다 (git commit -m 'Add some AmazingFeature').

3. 브랜치에 푸시합니다 (git push origin feature/AmazingFeature).

4. Pull Request를 열어주세요.
